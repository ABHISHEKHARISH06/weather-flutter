# 🌦️ Weather App — Overview  
A cross-platform weather application built using Flutter, designed to deliver real-time weather updates with a clean and responsive UI. This project showcases multi-language integration including Dart, C++, and Swift, and leverages CMake for platform-specific builds.

## 🚀 Key Features  
- **Live Weather Data**  
  - Displays current weather conditions based on user location.  
  - Includes temperature, humidity, and atmospheric pressure.

- **Cross-Platform Support**  
  - Built with Flutter for Android and iOS compatibility.  
  - Uses CMake and MSBuild for native module integration.

- **Modular Architecture**  
  - Clean separation of UI, logic, and data layers.  
  - Easy to extend and maintain.
